# Spot Micro 전원부 설계

## 1. 개요

12개의 Feetech STS3215 서보, Jetson Orin Nano 8GB, STM32F446RE Nucleo-64를 안정적으로 구동하기 위한 전원 분배 시스템. 

**Jetson 전원을 서보/STM32 라인과 분리하여 노이즈 영향을 최소화**하는 것을 핵심 설계 원칙으로 함.

---

## 2. 전원 소스

| 용도 | 사양 | 비고 |
|---|---|---|
| 데모/실전 | 3S LiPo 7200mAh (100 ~ 200C) | XT60 커넥터, 셀 체커 장착 |
| 벤치/개발 | SMPS 12V 200W JmDisplay | 회로 디버깅, 장시간 시험 |
| 전환 방식 |  | XT60 커넥터 물리적 교체 |



---

## 3. 전원 분배 토폴로지

```
 [3S LiPo or SMPS]
            │
         XT60 (On/Off 역할 겸용)
            │
       ATO 30A 퓨즈 (인라인)
            │
       XT60 Y-Splitter
        ┌───┴───────────────────┐
        │ 서보 + STM32 분기       │ Jetson 분기
        │                        │
        ▼                        ▼
      [PDB]                [Buck-Boost
        │                     12V → 19V]
   ┌────┼────┬────┬────┐         │
   ▼    ▼    ▼    ▼    ▼         ▼
  Leg  Leg  Leg  Leg  [5V BEC]   Jetson Orin Nano
  FL   FR   RL   RR    │         (배럴잭)
   │    │    │    │    ▼
  3×   3×   3×   3×   STM32 Nucleo F446RE
       STS3215
```

**Y-Splitter 분리 이유**:
1. **전압 도메인 분리**: Jetson Orin Nano는 19V 배럴잭 입력이 필요하므로 별도 Buck-Boost 컨버터가 필수. PDB의 12V BEC 출력은 500mA 한계로 Jetson 피크(약 2A) 구동 불가

2. **노이즈 격리**: 12개 서보가 동시 스위칭할 때 발생하는 전류 리플이 Jetson 전원 평면을 통해 전파되는 것을 물리적으로 차단. STM32는 BEC의 step-down 컨버터가 1차 필터 역할

3. **고장 전파 차단**: Jetson 측 단락이 서보/STM32 측에 영향 없음 (반대 방향도 마찬가지)

## 4. 주요 부품 사양

### 4.1 퓨즈
| 항목 | 값 |
|---|---|
| 형식 | 차량용 40A ATO 퓨즈 |
| 위치 | 배터리 XT60 직후 |
| 착탈 | 퓨즈 홀더 양단 XT60으로 배터리 측에 체결 |

**40A 선정 근거**: 12 서보 × 2.7A 스톨 = 32A 피크 + Jetson/STM32 약 2A → 피크 34A. 15% 마진으로 40A.

### 4.2 PDB (Power Distribution Board)
- 입력: 12V (LiPo 배터리 또는 SMPS)
- 출력 1: 4 채널 × 다리당 STS3215 3개 (총 12개)
- 출력 2: 5V BEC 분기 → STM32
- 배선: 14~16 AWG, Star topology

### 4.3 Jetson 전원: Buck-Boost (LTC3780 7A)
| 항목 | 값 |
|---|---|
| 입력 | 12V (3S LiPo 만충 12.6V ~ 방전 컷오프 10.2V) |
| 출력 | **19V 고정** |
| 출력 전류 | 연속 3.5A 이상 |
| 입출력 캡 | 330µF × 2 (RVT 전해) |
| 대상 | Jetson Orin Nano 배럴잭 |

**19V 출력 선정 근거**:
- Jetson 입력 범위 7~20V 중 공식 어댑터 사양과 일치
- Buck-Boost 입력(12V)이 출력(19V)보다 항상 낮아 **부스트 모드 고정** → Buck↔Boost 전환 구간(약 11~13V)을 회피하여 전원 안정성 확보
- LiPo 방전 시 12.6V→10.2V로 변동해도 출력 19V 유지

### 4.4 STM32 전원: BEC (LM2596)
- 입력: **PDB 12V 분기**
- 출력: 5V / 2A
- 대상: STM32 Nucleo-64 (5V 핀)
- BNO055 IMU 3.3V는 STM32 온보드 LDO에서 공급

**PDB에서 BEC로 분기한 이유**:
- 서보와 STM32 모두 동일한 12V 도메인을 공유하므로 추가 분배기 불필요
- BEC의 step-down 스위칭이 서보 측 리플에 대한 1차 필터 역할
- 만능기판에 BEC 모듈을 두고 STM32 5V 핀에 직결

## 5. 전류 예산

| 부하 | 연속 | 피크 | 비고 |
|---|---|---|---|
| 시스템 합계 | ~10A | ~12A | 3S 12V 기준 |
| 서보 12개 | 2~8A | 10A | 보행 중 평균 0.6A/서보, 스톨 2A |
| Jetson Orin Nano | 1.3A (12V 환산) | 2A | MAXN_SUPER 모드 |
| STM32 + IMU 센서 | <0.5A | <0.5A | BNO055, 통신 버퍼 포함 |

**LiPo C-Rate 마진**: 7200mAh × 100C = 720A 방전 가능 → 12A 대비 **60배 이상 마진**.

**SMPS 마진**: 16.5A 제공 → 12A 대비 **1.4배 마진**.

## 6. 접지 설계 (Star Grounding)

모든 GND는 **배터리 (-) 단자 근처 단일 지점**에서 합류.

```
배터리 (-) ─┬─ 서보 GND (PDB 경유)
            ├─ STM32 GND (BEC → PDB 경유)
            ├─ Jetson GND (Buck-Boost 경유)
            └─ 만능기판 공통 GND 버스 (센서, 신호선)
```

신호선 GND와 전원 GND를 **단일 지점에서만 연결**하여 그라운드 루프 방지.

## 7. LiPo 운용 안전

- **셀 체커**: 3S 밸런스 커넥터에 장착, 셀당 3.3V 알람
- **저전압 보호**: Buck-Boost UVLO 약 10.2V (셀당 3.4V) 설정
- **단락 보호**: ATO 40A 퓨즈가 1차 보호
- **충전**: XT60 분리 후 전용 밸런스 충전기(IMax B6) 사용
- **보관**: Storage 전압 (셀당 3.8V) 유지, LiPo 안전 가방 내 보관
